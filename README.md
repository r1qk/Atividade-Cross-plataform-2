### Atividade da aula 4

Durante a aula 4 de Cross-Platform Application Development, aprendemos sobre estados, hooks (useEstate e useEffect) e estudamos mais sobre a estilização do React Native. Esta atividade foi proposta para personalizarmos o exemplo passsado durante a aula. Aqui precisávamos criar uma aplicação que contava quantos copos de água uma pessoa tomou, mostrar a quantia e exibir mensagens em relação a quantidade de copos. Também há um botão para recomeçar a contagem.
